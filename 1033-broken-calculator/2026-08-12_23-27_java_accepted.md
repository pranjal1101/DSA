## Solution

```java
class Solution{
    public int brokenCalc(int X,int Y){
        int ops=0;
        while(Y>X){
            ops++;
            if(Y%2==0) Y/=2;
            else Y++;
        }
        return ops+(X-Y);
    }
}

```
